# RIR shared-data cache widget

This package is a small update to the previously tested widget. It keeps the existing `get_sla_analytics_data` Custom API name and all quote, image, and customer selection logic.

First install the cache forms and functions in `INSTALL_AND_TEST.txt`. Test the function in RIR, then upload this widget package. When the saved copy is stale, a persistent Last updated notice appears. There is no refresh button.

This package does not install the Creator forms or Deluge functions for you.
